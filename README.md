# ClaudeCodeProjects

Colección de proyectos creados con Claude Code.

## Estructura

```
.
├── projects/   # Un directorio por proyecto
├── docs/       # Documentación y notas generales
├── CLAUDE.md   # Instrucciones para Claude Code
└── README.md
```

## Cómo agregar un proyecto

1. Crear una carpeta nueva dentro de `projects/` (por ejemplo `projects/mi-proyecto`).
2. Agregar un `README.md` propio con la descripción y cómo ejecutarlo.
3. Hacer commit y push.
