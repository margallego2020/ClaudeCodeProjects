# ClaudeCodeProjects

Repositorio con varios proyectos independientes creados con Claude Code.

## Convenciones

- Cada proyecto vive en su propia carpeta dentro de `projects/`.
- Cada proyecto tiene su propio `README.md` con descripción y modo de uso.
- Los README y la documentación se escriben en español.
- Mensajes de commit cortos y descriptivos.
- No subir secretos, tokens ni archivos `.env`.
