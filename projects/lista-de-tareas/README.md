# Lista de tareas

Proyecto de ejemplo: una lista de tareas por línea de comandos en Python (solo biblioteca estándar).

## Uso

```bash
python3 tareas.py agregar "Aprender Claude Code"
python3 tareas.py listar
python3 tareas.py completar 1
python3 tareas.py eliminar 1
```

Las tareas se guardan en `tareas.json` junto al script.

## Tests

```bash
python3 -m unittest
```
